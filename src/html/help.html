🚀 How to Use MicroBRSoils

MicroBRSoils was designed to be intuitive and scientifically rigorous, enabling users to explore and contextualize the microbial composition of Brazilian soils.

Brazil hosts some of the most diverse agroecosystems on Earth. Here you can explore microbial communities across crops, regions, and management systems — from coffee plantations in Cerrado and Mata Atlântica to adjacent native vegetation reference sites, as described in the project design.

🔍 1. Taxonomic Search

Filter samples by phylum, class, family, genus, or species. Use this tool to answer questions such as:

  • Where is a given taxon abundant?
  • Does it respond to fertilization, pH, or management practices?
  • How does it differ between agricultural and native soils?

You may also run sequence similarity searches (≥98% identity) to find samples containing sequences similar to your own.

🌎 2. Geo-Search & Metadata Exploration

Visualize sampling locations on an interactive map. You can:

  • Select samples by biome, crop, soil type, or productivity class.
  • Download raw FASTQ, metadata, and processed taxonomic profiles.
  • Compare community patterns between managed and conserved areas.

This feature draws directly on the project’s standardized sampling design across biomes and productivity gradients.

📤 3. Sample Upload (Coming Soon)

External sample submission will be enabled after the platform’s first stable release.

Registered users will be able to upload their own Illumina or IonTorrent metabarcoding datasets and receive:

  • ✔ Automated quality filtering and taxonomic profiling
  • ✔ Alpha diversity metrics
  • ✔ Beta diversity comparison against reference soils
  • ✔ Soil Quality Index estimation (beta version)
  • ✔ Access to a harmonized metadata template (TXT format)

Upload Requirements

  • Demultiplexed FASTQ files (single or paired-end)
  • Metadata file (.txt) following MicroBRSoils guidelines
  • Target genes: 16S rRNA, ITS, and (future releases) shotgun metagenomics

This ensures compatibility with the analytical workflows described in the project (e.g., 515F/806R and ITS1F/ITS2 markers).

📊 4. Interpretation & Insights

Once processed, users can navigate:

  • Community composition plots
  • Diversity indices
  • Relative abundance heatmaps
  • Environmental correlations (pH, nutrients, texture, enzymatic activity)
  • Comparisons with native soils as ecological baselines

In future iterations, AI models trained on the microBRsoil dataset will provide:

  • Predictive soil quality scores
  • Management sensitivity alerts
  • Interpretability dashboards
  • Prescriptive recommendations based on microbiome patterns
